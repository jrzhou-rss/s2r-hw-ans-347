第 3 章 恆等式

Ex 3A 恆等式的判定

恆等式：若一個方程的左右兩方的同類項完全相同，則該方程必定是恆等式。
1. 證明下列各方程是恆等式。
(a) $4(2x+5)=8x+20$

左方 $=4(2x+5)$
$=4(2x)+4(5)$
$= \underline{\text{ $8x+20$ }}$

右方 $= 8x+20$

左方 ( = / $\neq$ ) 右方
$\therefore$ 這方程 ( 是 / 不是 ) 恆等式。
(b) $2x(3x-1)=6x^{2}-2x$

左方 $= 2x(3x-1)$
$= 2x(3x)-2x(1)$
$= \underline{\text{ $6x^{2}-2x$ }}$

右方 $= 6x^{2}-2x$

左方 ( = / $\neq$ ) 右方
$\therefore$ 這方程 ( 是 / 不是 ) 恆等式。
2. 證明下列各方程是恆等式。
(a) $3(10a-5)-3=6(5a-3)$

左方 $= 3(10a-5)-3$
$= 3(10a)-3(5)-3$
$= \underline{\text{ $30a-18$ }}$

右方 $= 6(5a-3)$
$= 6(5a)-6(3)$
$= \underline{\text{ $30a-18$ }}$

左方 ( = / $\neq$ ) 右方
$\therefore$ 這方程 ( 是 / 不是 ) 恆等式。
(b) $(x+7)(x-3)=x^{2}+4x-21$

左方 $= (x+7)(x-3)$
$= x(x)-x(3)+7(x)-7(3)$
$= x^{2}-3x+7x-21$
$= \underline{\text{ $x^{2}+4x-21$ }}$

右方 $= x^{2}+4x-21$

左方 ( = / $\neq$ ) 右方
$\therefore$ 這方程 ( 是 / 不是 ) 恆等式。

Ex 3A 求恆等式中的未知常數

係數比較法：恆等式中左右兩方的同類項必定相同，利用這個原理，我們可以求出一些恆等式中未知常數的值。
1. 求下列各恆等式中的未知常數 A 及 B。
(c) $3(2x-8) \equiv Ax+B$
展開左方： $3(2x)-3(8) \equiv Ax+B$
$6x - 24 \equiv Ax+B$
比較恆等式的左方和右方，可得：
$\therefore A = \underline{\text{ $6$ }}$, $B = \underline{\text{ $-24$ }}$
2. 若 $x(5x+2) \equiv Ax^{2}+Bx$，其中 A 和 B 為常數，求 A 和 B 的值。
展開左方： $x(5x+2) \equiv Ax^{2}+Bx$
$x(5x)+x(2) \equiv Ax^{2}+Bx$
$5x^{2}+2x \equiv Ax^{2}+Bx$
比較恆等式的左方和右方，可得：
$\therefore A = \underline{\text{ $5$ }}$, $B = \underline{\text{ $2$ }}$
3. 若 $(2x-3)(x+5) \equiv 2x^{2}+Ax+B$，其中 A 和 B 為常數，求 A 和 B 的值。
展開左方：
$(2x-3)(x+5) \equiv 2x^{2}+Ax+B$
$2x(x)+2x(5)-3(x)-3(5) \equiv 2x^{2}+Ax+B$
$2x^{2}+10x-3x-15 \equiv 2x^{2}+Ax+B$
$2x^{2}+7x-15 \equiv 2x^{2}+Ax+B$
比較恆等式的左方和右方，可得：
$\therefore A = \underline{\text{ $7$ }}$, $B = \underline{\text{ $-15$ }}$

Ex 3B 平方差的恆等式

平方差恆等式：$(a+b)(a-b) \equiv a^{2}-b^{2}$
1. 展開下列各式。
(a) $(x+4)(x-4)$
$= (x)^{2}-(4)^{2}$
$= \underline{\text{ $x^{2}-16$ }}$
(b) $(3a+1)(3a-1)$
$= (3a)^{2}-(1)^{2}$
$= \underline{\text{ $9a^{2}-1$ }}$
(c) $(6+5p)(6-5p)$
$= (6)^{2}-(5p)^{2}$
$= \underline{\text{ $36-25p^{2}$ }}$
(d) $(2+3a)(3a-2)$
$= (3a+2)(3a-2)$
$= (3a)^{2}-(2)^{2}$
$= \underline{\text{ $9a^{2}-4$ }}$

Ex 3C 全平方的恆等式

完全平方恆等式：
$(a+b)^{2} \equiv a^{2}+2ab+b^{2}$
$(a-b)^{2} \equiv a^{2}-2ab+b^{2}$
1. 利用完全平方的恆等式，展開下列各式。
(a) $(y+5)^{2}$
$= (y)^{2}+2(y)(5)+(5)^{2}$
$= \underline{\text{ $y^{2}+10y+25$ }}$
(b) $(a+4)^{2}$
$= (a)^{2}+2(a)(4)+(4)^{2}$
$= \underline{\text{ $a^{2}+8a+16$ }}$
(c) $(5m+6)^{2}$
$= (5m)^{2}+2(5m)(6)+(6)^{2}$
$= \underline{\text{ $25m^{2}+60m+36$ }}$
2. 利用完全平方的恆等式，展開下列各式。
(a) $(x-7)^{2}$
$= (x)^{2}-2(x)(7)+(7)^{2}$
$= \underline{\text{ $x^{2}-14x+49$ }}$
(b) $(8y-3)^{2}$
$= (8y)^{2}-2(8y)(3)+(3)^{2}$
$= \underline{\text{ $64y^{2}-48y+9$ }}$
(c) $(x-5y)^{2}$
$= (x)^{2}-2(x)(5y)+(5y)^{2}$
$= \underline{\text{ $x^{2}-10xy+25y^{2}$ }}$
(d) $(4-7h)^{2}$
$= (4)^{2}-2(4)(7h)+(7h)^{2}$
$= \underline{\text{ $16-56h+49h^{2}$ }}$

第 4 章 代數分式

Ex 4A 代數分式的化簡

1. 化簡下列各代數分式。（提示：消去公因式）
(a) $\dfrac{6}{2y}$
$= \underline{\text{ $\dfrac{3}{y}$ }}$
(b) $\dfrac{15c^{3}d^{2}}{5cd}$
$= \underline{\text{ $3c^{2}d$ }}$
2. 化簡下列各代數分式。（提示：消去公因式）
(a) $\dfrac{6(a+b)}{2(a+b)}$
$= \underline{\text{ $3$ }}$
(b) $\dfrac{20x+10y}{5y}$
$= \dfrac{10(2x+y)}{5y}$
$= \underline{\text{ $\dfrac{2(2x+y)}{y}$ }}$
3. 化簡下列各代數分式。
(a) $\dfrac{2a}{3b} \times \dfrac{6b}{4a}$
$= \underline{\text{ $1$ }}$
(b) $\dfrac{c}{7d} \times \dfrac{14d^{3}}{c^{2}}$
$= \underline{\text{ $\dfrac{2d^{2}}{c}$ }}$
(c) $\dfrac{5}{9b} \div \dfrac{5a}{18b^{2}}$
$= \dfrac{5}{9b} \times \dfrac{18b^{2}}{5a}$
$= \underline{\text{ $\dfrac{2b}{a}$ }}$
4. 化簡下列各代數分式。（提示：同分母，分子可直接加減。）
(a) $\dfrac{5x}{3y} + \dfrac{7x}{3y}$
$= \dfrac{5x + 7x}{3y}$
$= \dfrac{12x}{3y}$
$= \underline{\text{ $\dfrac{4x}{y}$ }}$
(b) $\dfrac{4x}{3x-1} - \dfrac{x}{3x-1}$
$= \dfrac{4x - x}{3x-1}$
$= \underline{\text{ $\dfrac{3x}{3x-1}$ }}$

Ex 4B 公式和代入法

1. 已知 $P = 4I$。若 $I = 7$，求 P 的值。
$P = 4(7)$
$P = \underline{\text{ $28$ }}$
2. 已知 $D = ST$。若 $D = 35$ 及 $S = 5$，求 T 的值。
$(35) = (5)T$
$\dfrac{35}{5} = T$
$T = \underline{\text{ $7$ }}$
3. 已知公式 $u = v - at$，若 $u = 9$、$a = 1$ 及 $t = 3$，求 v 的值。
$u = v - at$
$(9) = v - (1)(3)$
$(9) + (3) = v$
$v = \underline{\text{ $12$ }}$

Ex 4C 公式主項的變換

1. 已知公式 $P = a + b + c$，令 a 成為公式的主項。
$P = a + b + c$
$P - b - c = a$
$a = \underline{\text{ $P - b - c$ }}$
2. 已知公式 $3x - 5 = y$，令 x 成為公式的主項。
$3x - 5 = y$
$3x = y + 5$
$x = \underline{\text{ $\dfrac{y+5}{3}$ }}$
3. 已知公式 $R = sa - sk$，令 s 成為公式的主項。
$R = sa - sk$
$R = s(a - k)$
$\dfrac{R}{a - k} = s$
$s = \underline{\text{ $\dfrac{R}{a-k}$ }}$

第 7 章 續數據的處理

Ex 7A 數據的組織

例：假設把一組數據按以下組區間分組：$5\text{m}-9\text{m}, 10\text{m}-14\text{m}, 15\text{m}-19\text{m}$ 等。
對於組區間 $10\text{m}-14\text{m}$：
(a) 下組限 $= 10\text{m}$，上組限 $= 14\text{m}$
(b) 組中點 $= \dfrac{\text{下組限}+\text{上組限}}{2} = \dfrac{10+14}{2}\text{m} = 12\text{m}$
(c) 下組界 $= 9.5\text{m}$，上組界 $= 14.5\text{m}$
(d) 組距 $= \text{上組界}-\text{下組界} = (14.5-9.5)\text{m} = 5\text{m}$
1. 完成下表。
組區間 下組限 上組限 組中點 下組界 上組界 組距
10-19 10 19 $\dfrac{10+19}{2} = \mathbf{14.5}$ 9.5 19.5 10
20-29 20 29 $\dfrac{20+29}{2} = \mathbf{24.5}$ 19.5 29.5 10
2. 參看以下的頻數分佈表。
組區間 1-10 11-20 21-30 31-40 41-50
頻數 3 4 9 7 2

寫出頻數最高和頻數最低的組區間：

頻數最高的組區間：21-30

頻數最低的組區間：41-50

3. 下表所示為一些學生於某天溫習的時間。
時間 (min) 30-59 60-89 90-119 120-149 150-179
頻數 3 9 20 7 1
(a) 求第三個組區間的組中點。
組中點 $= \dfrac{90+119}{2} = \underline{\text{ $104.5$ }}\text{ min}$

(b) 求第三個組區間的上組限和下組限。
上組限 $= \underline{\text{ $119$ }}\text{ min}$，下組限 $= \underline{\text{ $90$ }}\text{ min}$

(c) 求第三個組區間的上組界和下組界。
上組界 $= \underline{\text{ $119.5$ }}\text{ min}$，下組界 $= \underline{\text{ $89.5$ }}\text{ min}$
4. 下表所示為一些學生在陸運會中的跳遠成績。
距離 (cm) 100-149 150-199 200-249 250-299 300-349
頻數 5 10 12 7 6
(a) 求跳遠成績低於 $199.5\text{ cm}$ 的學生數目。
所需學生數目 $= 5 + 10 = \underline{\text{ $15$ }}$ 人

(b) 求跳遠成績低於 $299.5\text{ cm}$ 的學生數目。
所需學生數目 $= 5 + 10 + 12 + 7 = \underline{\text{ $34$ }}$ 人

(b) 該工作坊內共有多少件手工藝品？
手工藝品的數目 $= 4 + 14 + 36 + 18 + 8 = \underline{\text{ $80$ }}\text{ 個}$
